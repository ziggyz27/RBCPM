# Block by Block

An animated, click-controlled walkthrough of nine reusable ServiceNow platform
capabilities (auth/MFA, data source connect, table view, export controls,
notifications, multi-layer approval chain, view/print/export guardrails,
time-bound access, workflow trigger) assembling into one governed self-serve app.

**Live page:** enable via GitHub Pages settings — served from `index.html` on `main`.

Navigate with Next/Prev, click any block or progress dot to jump to that step,
arrow keys, or press Play for an automatic Slow/Normal/Fast walkthrough.
